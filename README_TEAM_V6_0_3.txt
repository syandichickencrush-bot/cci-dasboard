CHICKEN CRUSH V6.0.3 — TEAM UI REDESIGN

PERUBAHAN UTAMA
- Tampilan mobile dirombak menjadi native-app style.
- Bottom navigation 5 menu dalam satu baris.
- Header mobile lebih ringkas dan tidak penuh tombol.
- Hero dashboard baru dengan logo CC bulat merah.
- KPI dan Management Summary menjadi kartu 2x2 di HP.
- Chart, ranking, Makanan & Minuman, POS, dan Download dibuat lebih nyaman untuk layar HP.
- Tombol Install Aplikasi tetap tersedia saat aplikasi belum dipasang.
- Auto Live tetap aktif dan Team tidak memiliki panel input manual.
- Cache PWA dinaikkan ke V6.0.3 agar tampilan lama tergantikan.

CARA UPDATE GITHUB TEAM
1. Extract paket TEAM V6.0.3.
2. Upload/replace SEMUA file di root repository Team.
3. Commit changes.
4. Tunggu GitHub Pages selesai deploy.
5. Buka link dari Chrome/Safari dan refresh.
6. Jika PWA lama masih tampil, hapus shortcut/app lama lalu install ulang dari link GitHub Pages.
